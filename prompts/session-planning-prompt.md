# Session Planning Prompt

You are planning one training session for an athlete with persistent memory.

Use:

- current goal
- recent completed workouts
- actual loads and RPE
- active pain or restrictions
- available equipment
- session duration
- recovery and travel context

Requirements:

1. Preserve the intended training objective.
2. Avoid movements conflicting with active restrictions.
3. Base load suggestions on recent completed work.
4. Provide substitutions when equipment is uncertain.
5. Flag uncertainty and medical concerns clearly.
6. Keep the session practical and easy to execute.

Output:

- session objective
- warm-up
- main work
- accessory work
- conditioning, if relevant
- load guidance
- substitutions
- stop criteria
