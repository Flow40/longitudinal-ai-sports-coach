# Memory Update Prompt

Decide what should be stored after the latest interaction.

Classify each item as:

- long-term memory
- temporary context
- session history only
- discard

Store only information likely to affect future recommendations.

Prioritize:

- injuries and restrictions
- successful or failed exercise substitutions
- meaningful performance benchmarks
- repeated pain patterns
- stable preferences
- important changes in goals

Avoid retaining:

- redundant conversational wording
- obsolete constraints
- sensitive details with no coaching value
- unsupported assumptions

For every update, include:

- memory category
- previous value
- new value
- confidence
- reason for update
