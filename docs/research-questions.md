# Research Questions

## Primary Questions

1. How much does long-term memory improve relevance compared with isolated prompts?
2. Which categories of memory contribute most to training quality?
3. Can memory reduce repeated unsafe or irrelevant recommendations?
4. How should old information be summarized, corrected or forgotten?
5. How can recommendation quality be evaluated over time?

## Secondary Questions

- How does the system handle conflicting information?
- How should pain and medical context be weighted?
- Can progression recommendations be benchmarked?
- What is the minimum useful memory schema?
- How should privacy and user control be designed?
- What role should a human coach or clinician retain?
